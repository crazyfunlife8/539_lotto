# 39彩金桶 — 區塊鏈版

39 選 5 彩金桶遊戲的區塊鏈重製版，以 TRON 鏈 + USDT（TRC20）為底層，支援多語系（繁中／簡中／英文）。

> **目前階段：規格設計 + 前端原型**
> 智能合約尚未開發；本 repo 包含完整設計文件與可瀏覽的靜態前台／後台原型。

## 技術棧

| 層次 | 技術 | 說明 |
|---|---|---|
| 區塊鏈 | TRON | 手續費低，目標用戶熟悉 |
| 代幣 | USDT（TRC20） | 全站計價單位 |
| 智能合約 | Solidity（TronBox） | 3 個不可升級合約 |
| 預言機 | 自建多簽 | TRON 無現成外部預言機 |
| 前端 | 純 HTML / Tailwind CSS / Vanilla JS | 零框架依賴，靜態部署 |
| 多語系 | 自建 i18n.js | 繁中、簡中、英文 |

## 下注方式（第一版）

| 方式 | 說明 |
|---|---|
| ① 授權下注 | 玩家授權資金合約扣款，平台代付 Energy |
| ② 轉帳下注 | 玩家直接 USDT 轉帳，玩家自付手續費 |
| ③ 儲值餘額 | 玩家預存餘額至合約，平台代付 Energy |
