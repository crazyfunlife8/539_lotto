## 1. 全站共通

### 1.1 版面框架

| 區塊 | 內容 |
|---|---|
| 頁首 | 〔品牌名〕標誌（回首頁）、語言切換（英／繁中／簡中）、連接錢包按鈕（已連接時顯示遮蔽地址＋遊戲餘額）、選單按鈕（☰） |
| 選單（☰） | 首頁、我的注單、會員中心、歷史紀錄、推廣夥伴、遊戲規則、客服 |
| 頁尾 | 遊戲規則、風險揭露、合約地址（3 個，可點開區塊鏈瀏覽器）、審計報告連結、Telegram 客服 |

### 1.2 資料來源原則

| 資料 | 來源 | 原因 |
|---|---|---|
| 遊戲餘額、頭獎彩池、自己的柱單、授權額度、期別狀態 | **直接讀鏈上合約** | 跟錢有關的數字不經過平台伺服器，玩家看到的就是鏈上真值 |
| 歷史紀錄、跑馬燈、推廣統計、下注與資金紀錄列表 | 索引服務 API | 列表查詢鏈上做不到或太慢 |
| 公告、跑馬燈文案 | 後台 API | 鏈下內容 |

鏈上資料以「監聽合約事件＋每 30 秒輪詢」自動更新，不設手動重新整理按鈕。

### 1.3 時間顯示

- 所有時間以**玩家裝置所在時區**顯示，並在旁標註官方時間。例：「截止 20:20（台灣時間）／你的時間 13:20」。
- 倒數計時以區塊時間校正，避免玩家手機時間不準。

### 1.4 錢包狀態處理

| 狀況 | 畫面行為 |
|---|---|
| 沒裝錢包 | 跳出提示，列出支援錢包與安裝連結【待定：支援清單 V6】 |
| 錢包未連接 | 可瀏覽所有頁面、選號、加入購物車；付款、儲值、提領、改單取消時才要求連接 |
| 連到錯誤網路（例如測試網） | 全站頂部紅色橫幅，所有交易按鈕停用 |
| 錢包 TRX 不足以付 bandwidth | 送交易前提示「需要少量 TRX 支付網路費用」，說明原因與大約金額 |
| 交易送出中／成功／失敗 | 統一的交易狀態視窗：送出中（附區塊瀏覽器連結）→ 成功／失敗（附失敗原因白話說明與重試按鈕） |
| 地址在黑名單 | 下注相關按鈕停用，顯示「此地址目前無法下注，餘額可正常提領」 |
| 全域停收新注 | 首頁與選號頁橫幅「目前暫停下注」，提領照常 |

### 1.5 地址遮蔽

公開顯示他人地址時，保留前 5 碼與後 4 碼，例如 `TXyzA…b12c`。

### P2 選號下注（每桶一頁）

**號碼區**

| 項目 | 規則 |
|---|---|
| 號球 | 1–39，點一下選取變亮，再點一下取消 |
| 上限 | 已選 5 顆時點第 6 顆：不動作，提示 `bet.max_five` |
| 加入購物車 | 剛好 5 顆時才可按；加入後號碼區清空，可繼續選下一組；不需先連接錢包 |
| 隨機選號 | 一鍵隨機選出 5 顆（可重按換一組） |
| 重下上期號碼 | 一鍵把自己上一期的全部號碼組帶入購物車（需已連接錢包） |
| 收藏號碼 | 購物車每組旁有「收藏」；號碼區旁列出已收藏組合，一鍵帶入；資料存鏈下、綁定錢包地址 |
| 購物車 | 列出每組號碼，可刪除單組；顯示組數 × 每注金額 = 總額；組數上限【待定】 |

**確認視窗**：每組 5 顆球的排列、總金額、提示 `bet.confirm.notice`（截止前可修改或取消，截止後無法更改）。

**選擇下注方式**

| 方式 | 可選條件 | 不可選時的提示 |
|---|---|---|
| ① 授權下注 | 永遠可選 | — |
| ② 轉帳下注 | 距截止超過 5 分鐘 | `bet.transfer.closed`（轉帳下注已於 20:15 停止） |
| ③ 餘額下注 | 遊戲餘額 ≥ 總額 | `bet.balance.insufficient`，附「去儲值」連結 |

**① 授權下注流程**

1. 若授權額度 < 總額：先顯示白話說明視窗 `approve.explain`（授權是什麼、這次授權多少、隨時可撤銷），預設授權金額 = 本次總額，可勾選「授權更多以省下次手續費」並輸入金額（不提供無限額）。
2. 錢包跳出授權 → 成功後自動進入下一步。
3. 錢包跳出下注交易 → 成功 → 成功視窗。

**② 轉帳下注流程**

1. 錢包跳出「簽署訊息」（說明 `transfer.sign.explain`：這不是授權、不花錢）。
2. 顯示轉帳資訊：彩金桶地址（含 QR code 與複製按鈕）、應轉金額、截止提醒；提供「用已連接錢包直接轉帳」按鈕。
3. 錢包送出轉帳後，前端立即把交易編號回報入帳服務。
4. 狀態顯示：等待區塊確認 → 登記中 → 成功（柱單出現在「我的柱單」）。
5. 異常情況（對應 PRD F5 ② 異常轉帳表）：
   - 截止後才到帳或來不及登記：說明已記入遊戲餘額，提供「一鍵改買下一期」（用餘額下注、預填原號碼）與提領按鈕。
   - 轉少：柱單沒有成立，已全額記入遊戲餘額。
   - 轉多：柱單成立，差額記入遊戲餘額。
   - 低於一注金額：暫不入帳，累積到一注金額後才入帳。

**③ 餘額下注流程**：錢包跳出下注交易 → 成功 → 成功視窗。

**成功視窗**：祝福語 `bet.success.title`（舊規劃原意：預祝旗開得勝、獨中彩金）、本次柱單摘要、「查看我的柱單」「繼續下注」按鈕。

### P3 我的柱單

| 區塊 | 內容 |
|---|---|
| 本期（未截止） | 每張柱單：號碼、下注方式、金額、狀態；「改號碼」「取消」按鈕（截止後隱藏） |
| 已截止、等待開獎 | 柱單列表，顯示「已收單，等待開獎」與鏈上該期開獎時間（`drawTime`，延期時自動更新） |
| 已開獎 | 開獎號碼、每張中幾碼（命中號碼標亮）、獎金、入帳狀態（已入餘額／已轉回錢包／轉回失敗已入餘額） |

**改號碼**：開啟號碼區預填原號碼 → 修改 → 確認 → 錢包簽一筆交易（不需授權、平台付 energy）。
**取消**：確認視窗 `ticket.cancel.confirm`（金額將退回遊戲餘額）→ 錢包簽一筆交易。

**特殊狀態顯示**

| 期別狀態 | 顯示 |
|---|---|
| 爭議中 | `period.disputed`：開獎結果確認中，確認後自動結算 |
| 平台固定獎金待付 | `prize.pending`：獎金處理中 |
| 退款中 | `period.refunding`：本期因官方開獎異常退款處理中；個別柱單退完即顯示「已退回遊戲餘額」 |
| 退款完成 | `period.refunded`：本期已全額退回遊戲餘額 |
| 已取消（截止前由平台取消） | `period.cancelled`：已全額退回遊戲餘額 |

### P5 歷史紀錄

- 依彩金桶分頁；預設列出最近幾期，可輸入期號查詢任一期。
- 每期：期號、開獎號碼、官方開獎頁連結、鏈上結果紀錄連結、彩池總額、中獎明細（遮蔽地址＋獲得金額）、其他下注明細（遮蔽地址＋所選號碼）。

### P6 推廣夥伴

| 區塊 | 內容 |
|---|---|
| 推廣連結 | 專屬連結（含推廣碼）＋複製＋QR code |
| 統計 | 第一層下線人數、第二層下線人數、各層下線下注總額 |
| 分潤 | 可領金額、「領取」按鈕（錢包簽一筆交易）、領取紀錄 |
| 說明 | 分潤比例【待定】、分潤在每期開獎結算後入帳、退款的期別不產生分潤 |

推廣碼保存：玩家從推廣連結進入時，推廣碼存在瀏覽器，直到第一次下注時寫上鏈綁定。

### P7 遊戲規則

- 玩法、每注金額、獎項表（從當期合約參數讀取，金額【待定】）。
- 每張柱單只領最高獎項；4 碼保底獎規則；頭獎 80% 派出、20% 留存；沒人中頭獎的處理【待定】。
- **固定獎金由平台保證支付。**
- 截止時間（20:20）、轉帳下注停止時間（20:15）、官方開獎時間（20:30）。
- 截止前可改單、取消；截止後不可更改。
- 開獎異常的處理：官方開獎後 72 小時未完成結算即全額退款。
- 三種下注方式說明、手續費說明。
- **風險揭露**：USDT 發行方可凍結任何地址（含本遊戲合約）、區塊鏈交易不可逆、受限地區不得使用【受限地區清單由合規團隊提供】。
- 合約地址與審計報告。

## 3. 後台

### 3.1 帳號與權限

- 後台帳號為鏈下帳號，登入須二次驗證。
- **後台帳號本身沒有任何合約權限**；需要上鏈的管理操作，一律產生「待簽交易」，由管理多簽簽署人用自己的錢包簽署後送出。

| 角色 | 可用功能 |
|---|---|
| 營運 | 內容管理、期別查看、收單報表、玩家查詢 |
| 客服 | 玩家查詢、無主款認領申請 |
| 財務 | 財務、營運報表 |
| 管理員 | 全部；可發起待簽交易 |

### 3.2 功能清單

| # | 頁面 | 內容 |
|---|---|---|
| A1 | 總覽 | 各桶本期狀態與倒數、頭獎彩池、平台戶餘額 vs 待付固定獎金、energy 存量、入帳服務與預言機運作狀態、未處理告警 |
| A2 | 內容管理 | 跑馬燈、系統公告、常見問題（各三語欄位、上下架、排程） |
| A3 | 期別管理 | 期別列表與狀態；手動建立期別（官方期號異動時補建，產生待簽交易，參數由合約自動套用現行設定）；**取消／延期（只在截止前可按，產生待簽交易）**；開獎結果與 3 台預言機回報對照；爭議裁定（產生待簽交易） |
| A4 | 收單報表 | 每期截止（20:20）後可匯出全部柱單：期號、柱單編號、地址、號碼、金額、下注方式；格式 CSV／Excel |
| A5 | 入帳監控 | ② 待付單、已登記、異常轉帳（已轉入餘額）、小額累積、無主款清單；每筆登記的交易編號與鏈上真實轉帳比對結果；入帳上限使用量；**暫停／更換入帳服務錢包**；入帳服務停擺超過 6 小時時**代為入帳**（以上皆產生待簽交易） |
| A6 | 無主款認領 | 客服提交認領申請 → 驗證玩家用原轉帳錢包的簽名 → 產生待簽交易；30 天未認領清理（產生待簽交易、等待 48 小時） |
| A7 | 玩家查詢 | 依地址查：餘額、柱單、資金紀錄、推廣關係；黑名單設定（產生待簽交易） |
| A8 | 推廣夥伴 | 夥伴列表、下線數、下線下注額、已發分潤 |
| A9 | 財務 | 平台戶餘額、待付固定獎金、平台注資／提款（產生待簽交易）、每期損益報表（下注額、派彩、頭獎提撥、分潤、平台份額） |
| A10 | 合約參數 | 現行參數檢視；修改提案（產生待簽交易，只影響之後新建的期別）；停收新注、彩金桶停用與新增；更換排程服務錢包；更換預言機簽名者（等待 48 小時）；入帳上限設定 |
| A11 | energy 監控 | 代付帳戶 energy 存量、每日消耗、預估可用天數、告警門檻 |
| A12 | 告警中心 | 告警列表、處理狀態；同時推送到營運人員的 Telegram |
| A13 | 操作紀錄 | 所有後台操作與待簽交易的紀錄（誰、何時、做了什麼），不可刪除 |

### 3.3 告警項目

| 告警 | 觸發條件 |
|---|---|
| 預言機分歧 | 3 台回報不一致，或期別進入爭議中 |
| 開獎結果延遲 | 官方開獎後 30 分鐘仍未上鏈 |
| 入帳服務停擺 | 超過 10 分鐘沒有心跳 |
| 入帳比對異常 | 登記的交易編號與鏈上真實轉帳不符 |
| 平台戶不足 | 平台戶 < 待付固定獎金，或低於預警水位【待定】 |
| energy 不足 | 低於預警水位【待定】 |
| 自動轉回失敗 | 任何一筆轉回失敗 |
| 無主款 | 出現新的無主款 |

### 3.4 待簽交易流程

1. 管理員在後台發起操作 → 系統產生待簽交易，列出白話摘要（例如「取消 539 第 115000240 期」）。
2. 管理多簽簽署人用自己的錢包逐一簽署（TRON 原生多簽，實作方式見 V5）。
3. 達到門檻後送出，結果回寫操作紀錄。
