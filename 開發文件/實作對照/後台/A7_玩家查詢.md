## UI 元素清單

| 元素 | 類型 | 說明 | 規格來源 |
|---|---|---|---|
| 地址搜尋輸入 | 文字輸入 | TRC20 地址 | §A7 |
| 查詢按鈕 | 按鈕 | 送出查詢 | §A7 |
| 遊戲餘額 | 數字顯示 | USDT，讀合約 | §A7 餘額 |
| 本期柱單列表 | 表格 | 柱單編號、號碼、金額、下注方式 | §A7 柱單 |
| 資金紀錄列表 | 表格 | 類型、金額（正負）、說明、時間；最多 N 筆 | §A7 資金紀錄 |
| 推廣關係 | 顯示區塊 | 上線地址（遮蔽）、下線數量 | §A7 推廣關係 |
| 黑名單狀態 | 狀態標籤 | 是否在黑名單中 | §A7 黑名單 |
| 加入黑名單按鈕 | 按鈕 → 待簽交易 | 管理員；未在黑名單時顯示 | §A7 / §3.4 |
| 解除黑名單按鈕 | 按鈕 → 待簽交易 | 管理員；已在黑名單時顯示 | §A7 / §3.4 |

## 排除清單（明確不做）

| 項目 | 原因 |
|---|---|
| 凍結餘額 | 黑名單只禁止下新注，不凍結既有餘額與獎金（§CLAUDE.md 黑名單） |
| 修改玩家資料 | 後台無此操作 |

## API 欄位對照

| UI 顯示 | API 欄位 | 端點 | 備註 |
|---|---|---|---|
| 遊戲餘額 | `balance` | `GET /admin/api/players/:address` | |
| 本期柱單 | `ticketId`, `numbers[]`, `amount`, `betMethod` | `GET /admin/api/players/:address/tickets?drawNo=current` | |
| 資金紀錄 | `type`, `amount`, `description`, `createdAt` | `GET /admin/api/players/:address/fund-history` | 分頁 |
| 推廣關係 | `referrerAddress`, `downlineCount` | `GET /admin/api/players/:address/affiliate` | |
| 黑名單狀態 | `blacklisted` | `GET /admin/api/players/:address` | |
| 加入黑名單 | `address` | `POST /admin/api/players/:address/blacklist` → 待簽交易 | |
| 解除黑名單 | `address` | `DELETE /admin/api/players/:address/blacklist` → 待簽交易 | |

## 按鈕與操作

| 按鈕 | 可用條件 | 觸發動作 | 規格來源 |
|---|---|---|---|
| 查詢 | 輸入有效地址 | GET 玩家資料，全部區塊顯示 | §A7 |
| 加入黑名單 | 管理員 + 未在黑名單 | 確認對話框 → 產生待簽交易 | §A7 / §3.4 |
| 解除黑名單 | 管理員 + 已在黑名單 | 確認對話框 → 產生待簽交易 | §A7 / §3.4 |
