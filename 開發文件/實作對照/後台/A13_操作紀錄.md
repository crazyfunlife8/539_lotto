# 實作對照：A13 操作紀錄

> 狀態：**✅ 靜態原型完成**（`dashboard/admin.html` #page-a13）
> 規格來源：`05_前後台功能規格.md` §3.2 A13、§3.4 待簽交易流程

---

## UI 元素清單

| 元素 | 類型 | 說明 | 規格來源 |
|---|---|---|---|
| 操作紀錄列表 | 表格 | 時間、操作者（帳號）、動作類型、詳細說明、關聯待簽交易（若有）| §A13 |
| 篩選：操作者 | 下拉 | 依帳號篩選 | §A13 |
| 篩選：動作類型 | 下拉 | 依動作分類篩選 | §A13 |
| 篩選：時間範圍 | 日期輸入 | 起訖日期 | §A13 |
| 待簽交易 txHash | 外部連結 | 可點開區塊瀏覽器查看 | §A13 |

## 排除清單（明確不做）

| 項目 | 原因 |
|---|---|
| 刪除操作紀錄 | 規格明確：**不可刪除** | §A13 |
| 編輯操作紀錄 | 同上，審計不可竄改 |

## 自動寫入時機

下列操作完成後系統自動寫入 A13，**不需要管理員手動操作**：

| 觸發來源 | 紀錄內容 |
|---|---|
| 任何後台表單送出 | 操作者、時間、動作摘要 |
| 待簽交易產生 | 待簽交易 txHash、參數摘要 |
| 待簽交易簽署達門檻並送出 | 送出結果（成功 / 失敗）|
| 告警標記已處理 | 操作者 + 告警 ID |

## API 欄位對照

| UI 顯示 | API 欄位 | 端點 | 備註 |
|---|---|---|---|
| 操作紀錄列表 | `id`, `operatorAccount`, `actionType`, `description`, `pendingTxHash`, `createdAt` | `GET /admin/api/audit-log` | 只讀；支援篩選參數 |

## 按鈕與操作

| 按鈕 | 可用條件 | 觸發動作 | 規格來源 |
|---|---|---|---|
| 待簽 txHash 連結 | 有 txHash 的紀錄 | 開新分頁至 TRON 區塊瀏覽器 | §A13 |
| 搜尋 / 篩選 | 任何角色 | GET 帶篩選參數 | §A13 |
