# 實作對照：後台共通

> 規格來源：`05_前後台功能規格.md` §3.1

---

## 帳號與角色權限

| 角色 | 可存取頁面 |
|---|---|
| 管理員 | A1–A13 全部；可發起待簽交易 |
| 營運 | A1、A2、A3（唯讀）、A4、A7 |
| 客服 | A6、A7 |
| 財務 | A1、A9、A13（唯讀）|

## 後台帳號規則

- 後台帳號為鏈下帳號（非錢包），登入須二次驗證（2FA）
- **後台帳號本身沒有任何合約權限**
- 需要上鏈的操作 → 產生待簽交易 → 管理多簽簽署人用自己的**錢包**簽署送出

## 待簽交易流程（§3.4）

1. 管理員在後台發起操作
2. 後台產生待簽交易，顯示白話摘要（例：「取消 539 第 115000240 期」）
3. 管理多簽簽署人用錢包逐一簽署（TRON 原生多簽）
4. 達門檻後送出，結果自動回寫 A13 操作紀錄

## 版面框架

| 元素 | 說明 |
|---|---|
| 左側欄（Sidebar） | Logo、導航選單（依角色顯示）、登出 |
| 頂欄（Topbar） | 頁面標題、台灣時間時鐘、登入帳號 + 角色 badge |
| 主內容區 | 各頁 page-section，同一時間只顯示一頁 |
| 告警 badge | 側欄告警中心旁顯示未處理數量 |
