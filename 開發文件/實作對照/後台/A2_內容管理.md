### API 欄位對照

| UI 顯示 | API 欄位 | 端點 | 備註 |
|--------|---------|------|------|
| 跑馬燈列表 | `id`, `en`, `zh_tw`, `zh_cn`, `status`, `scheduleStart`, `scheduleEnd` | `GET /admin/api/content/marquee` | |
| 新增跑馬燈 | 同上（無 id） | `POST /admin/api/content/marquee` | |
| 編輯跑馬燈 | 同上 | `PUT /admin/api/content/marquee/:id` | |
| 刪除跑馬燈 | — | `DELETE /admin/api/content/marquee/:id` | |
| 公告列表 | `id`, `titleEn`, `titleZhTw`, `titleZhCn`, `bodyEn`, `bodyZhTw`, `bodyZhCn`, `status`, `scheduleStart`, `scheduleEnd` | `GET /admin/api/content/announcements` | |
| 新增/編輯公告 | 同上 | `POST` / `PUT /admin/api/content/announcements/:id` | |
| FAQ 列表 | `id`, `questionEn`, `questionZhTw`, `questionZhCn`, `answerEn`, `answerZhTw`, `answerZhCn`, `status`, `sort` | `GET /admin/api/content/faq` | |
| 新增/編輯 FAQ | 同上 | `POST` / `PUT /admin/api/content/faq/:id` | |
| 排序 | `order[]` | `PUT /admin/api/content/faq/sort` | 傳完整排序陣列 |
