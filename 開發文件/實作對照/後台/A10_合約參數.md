## UI 元素清單

| 元素 | 類型 | 說明 | 規格來源 |
|---|---|---|---|
| 現行參數檢視表 | 唯讀表格 | 所有合約參數的現行值（見下方參數清單） | §A10 現行參數 |
| 修改提案按鈕 | 按鈕 → 表單 → 待簽交易 | 只影響之後新建的期別，不影響現行期 | §A10 修改提案 |
| 全局停收新注開關 | 按鈕 → 待簽交易 | 立即生效（前台顯示暫停橫幅） | §A10 停收 |
| 彩金桶停用按鈕 | 按鈕 → 待簽交易 | 停用特定彩金桶 | §A10 |
| 新增彩金桶按鈕 | 按鈕 → 表單 → 待簽交易 | 管理員；第一版暫時只需佔位 | §A10 |
| 更換排程服務錢包 | 按鈕 → 待簽交易 | 輸入新地址 | §A10 |
| 更換預言機簽名者 | 按鈕 → 待簽交易 | 輸入新地址；**等待 48 小時生效** | §A10 |
| 入帳上限設定 | 數字輸入 → 待簽交易 | 每期最大登記筆數 | §A10 |

## 可修改的合約參數清單

（依 `04_智能合約規格.md` 參數總表，此欄位名稱待合約規格確認後補齊）

| 參數 | 說明 | 待定 |
|---|---|---|
| 每注售價 | USDT，每注固定金額 | ⏳ 待經濟模型 |
| 頭獎提撥比例 | 每期下注額中撥入彩池的 % | ⏳ |
| 固定獎金（1–3碼） | 各獎項定額 USDT | ⏳ |
| 4碼保底獎 | 有人中 5 碼時的保底金額 | ⏳ |
| 彩池無人中保留比例 | 目前設計 20% 留存 | §CLAUDE.md 彩金桶 |
| 分潤比例（第一層） | 下注額的 % | ⏳ |
| 分潤比例（第二層） | 下注額的 % | ⏳ |
| 入帳上限（每期） | 最大登記筆數 | §A10 |

## 排除清單（明確不做）

| 項目 | 原因 |
|---|---|
| 直接修改進行中期別的參數 | 合約硬規則：修改只影響之後新建的期別 |
| 參數修改立即上鏈（無多簽） | 後台帳號無合約權限，一律待簽交易（§3.1） |

## API 欄位對照

| UI 顯示 | API 欄位 | 端點 | 備註 |
|---|---|---|---|
| 現行參數 | `params{}` 物件 | `GET /admin/api/contract/params` | 讀合約 |
| 修改提案 | `paramName`, `newValue` | `POST /admin/api/contract/params/pending-tx` → 待簽交易 | |
| 全局停收 | `action` (`pause`/`resume`) | `POST /admin/api/contract/global/pending-tx` | |
| 彩金桶停用 | `pool`, `action` (`disable`/`enable`) | `POST /admin/api/contract/pools/pending-tx` | |
| 更換排程錢包 | `newAddress` | `POST /admin/api/contract/scheduler/pending-tx` | |
| 更換預言機簽名者 | `oracleIndex`, `newAddress` | `POST /admin/api/contract/oracle/pending-tx` | 48 小時生效 |
| 入帳上限 | `limit` | `POST /admin/api/contract/deposit-limit/pending-tx` | |

## 按鈕與操作

| 按鈕 | 可用條件 | 觸發動作 | 規格來源 |
|---|---|---|---|
| 修改參數 | 管理員 | 填值 → 確認影響範圍說明 → 待簽交易 | §A10 / §3.4 |
| 全局停收 / 恢復 | 管理員 | 確認 → 待簽交易 | §A10 / §3.4 |
| 停用 / 啟用彩金桶 | 管理員 | 確認 → 待簽交易 | §A10 / §3.4 |
| 更換排程服務錢包 | 管理員 | 輸入地址 → 待簽交易 | §A10 / §3.4 |
| 更換預言機簽名者 | 管理員 | 輸入地址 → 待簽交易（48 小時後生效）| §A10 / §3.4 |
| 設定入帳上限 | 管理員 | 輸入數字 → 待簽交易 | §A10 / §3.4 |
