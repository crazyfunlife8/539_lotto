## 畫面：A1 總覽（路由：/admin/）

### UI 元素清單

| 元素 | 類型 | 說明 | 規格來源 |
|------|------|------|---------|
| 各桶本期狀態與倒數 | 狀態卡片 | 期號、狀態（收單中/已截止/開獎中/已結算）、截止倒數 | §A1 |
| 頭獎彩池 | 數字顯示 | 各桶當前彩池 USDT | §A1 |
| 平台戶餘額 vs 待付固定獎金 | 對比顯示 | 警示顏色（不足時紅色） | §A1 |
| energy 存量 | 數字 + 進度條 | 顯示剩餘量與預估可用天數 | §A1 |
| 入帳服務狀態 | 狀態燈 | 正常/停擺，上次心跳時間 | §A1 |
| 預言機運作狀態 | 狀態燈 × 3 | 3 台各自狀態 | §A1 |
| 未處理告警 | 告警清單 | 未處理數量 badge，展開列出最新 N 筆 | §A1 |

### API 欄位對照

| UI 顯示 | API 欄位 | 端點 | 備註 |
|--------|---------|------|------|
| 各桶狀態 | `status`, `drawNo`, `closingAt`, `countdown` | `GET /admin/api/pools/status` | |
| 頭獎彩池 | `jackpot` | `GET /admin/api/pools/status` | |
| 平台戶餘額 | `platformBalance` | `GET /admin/api/finance/summary` | |
| 待付固定獎金 | `pendingPayout` | `GET /admin/api/finance/summary` | |
| energy 存量 | `energyBalance`, `energyDailyUsage`, `energyDaysLeft` | `GET /admin/api/energy/status` | |
| 入帳服務 | `depositServiceStatus`, `depositLastHeartbeat` | `GET /admin/api/system/health` | |
| 預言機狀態 | `oracles[].id`, `oracles[].status`, `oracles[].lastReport` | `GET /admin/api/system/health` | |
| 未處理告警 | `alerts[].id`, `alerts[].type`, `alerts[].createdAt`, `alerts[].status` | `GET /admin/api/alerts?status=open` | |
