## UI 元素清單

| 元素 | 類型 | 說明 | 規格來源 |
|---|---|---|---|
| 平台戶餘額 | 數字顯示 | USDT，即時讀合約 | §A9 |
| 待付固定獎金 | 數字顯示 | 目前所有期別合計，讀合約 | §A9 |
| 安全緩衝倍數 | 計算顯示 | 餘額 ÷ 待付固定獎金 | §A9 |
| 平台注資按鈕 | 按鈕 → 待簽交易 | 輸入金額 → 管理員發起 | §A9 注資 |
| 平台提款按鈕 | 按鈕 → 待簽交易 | 輸入金額 → 管理員發起 | §A9 提款 |
| 每期損益報表 | 表格 | 期號、下注額、派彩、頭獎提撥、分潤、平台份額 | §A9 損益報表 |
| 報表篩選 | 日期範圍 / 期號範圍 | 篩選損益報表 | §A9 |
| 匯出報表按鈕 | 按鈕 | CSV / Excel | §A9 |

## 排除清單（明確不做）

| 項目 | 原因 |
|---|---|
| 直接轉帳（不走待簽交易） | 後台帳號沒有合約權限（§3.1） |
| 彩金桶彩池直接操作 | 彩池由合約自主管理 |

## API 欄位對照

| UI 顯示 | API 欄位 | 端點 | 備註 |
|---|---|---|---|
| 平台戶餘額 | `platformBalance` | `GET /admin/api/finance/summary` | 讀合約 |
| 待付固定獎金 | `pendingPayout` | `GET /admin/api/finance/summary` | 讀合約 |
| 注資 / 提款 | `amount`, `action` (`deposit`/`withdraw`) | `POST /admin/api/finance/pending-tx` → 待簽交易 | |
| 每期損益 | `drawNo`, `totalBet`, `payout`, `jackpotAlloc`, `affiliatePayout`, `platformShare` | `GET /admin/api/finance/pnl` | 分頁，支援期號範圍篩選 |
| 匯出 | — | `GET /admin/api/finance/pnl/export?format=csv` | |

## 按鈕與操作

| 按鈕 | 可用條件 | 觸發動作 | 規格來源 |

| 提款 | 財務 / 管理員 | 同上 | §A9 / §3.4 |
| 匯出報表 | 財務 / 管理員 | 下載 CSV / Excel | §A9 |
