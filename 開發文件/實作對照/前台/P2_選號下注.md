### 下注方式選擇

| 方式 | 可選條件 | 不可選提示 | 規格來源 |
|---|---|---|---|
| ① 授權下注 | 永遠可選 | — | §P2 |
| ② 轉帳下注 | 距截止 > 5 分鐘 | `bet.transfer.closed` | §P2 |
| ③ 餘額下注 | 遊戲餘額 ≥ 總額 | `bet.balance.insufficient`＋「去儲值」連結 | §P2 |

## 按鈕與操作

| 按鈕 | 觸發動作 | 需連接錢包 | 規格來源 |
|---|---|---|---|
| 加入注單 | 加入注單清單（本機狀態） | 否 | §P2 |
| 隨機選號 | 本機亂數選 5 顆 | 否 | §P2 |
| 重下上期號碼 | 讀 API 帶入注單 | 是 | §P2 |
| 收藏（注單） | 寫入鏈下收藏 API | 是 | §P2 |
| 確認下注 | 開啟確認視窗 | 是（無錢包時要求連接） | §P2 |
| 授權 ① | 送出授權交易 | 是 | §P2 ① |
| 下注（授權）① | 送出下注交易 | 是 | §P2 ① |
| 簽署訊息 ② | 錢包 signMessage | 是 | §P2 ② |
| 直接轉帳 ② | 送出 USDT transfer | 是 | §P2 ② |
| 下注（餘額）③ | 送出下注交易 | 是 | §P2 ③ |
